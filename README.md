# Threads Automation Starter

Threads 수집·분석·글 생성·연속 글 발행을 위한 로컬 웹 앱입니다.

## 설치와 실행

Node.js 20 이상과 npm을 준비한 뒤 이 폴더에서 실행하세요.

```sh
npm ci
npx playwright install chromium
npm start
```

브라우저에서 http://localhost:3579 를 여세요. 이미 사용 중인 포트라면 `PORT=3589 npm start`로 실행할 수 있습니다. 이 배포본은 127.0.0.1에만 연결됩니다.

## 각자 설정할 사항

- Threads 로그인은 앱에서 본인 계정으로 새로 진행합니다.
- AI 기능은 Claude Agent SDK를 사용합니다. 본인의 Claude Code 인증과 사용 가능한 구독/사용량이 필요합니다. 인증 오류 시 로컬 Claude Code에서 로그인 상태를 확인하세요.
- 개인 문체는 실행 후 생성되는 `data/persona/페르소나.md`에 작성합니다. 타겟·주제·CTA를 본인의 서비스에 맞게 정하세요.
- 현재 코드는 `src/intro.js`의 유튜브/전문직 마케팅 PD 자기소개를 교대로 사용합니다. 실제 직업과 다르다면 생성 전에 문구와 `startsWithIntro`의 검사 키워드를 함께 변경하세요.
- 이미지 서비스 기능은 본인의 별도 계정과 이미지 이용 권한이 있어야 합니다.

## 배포 범위

실행 코드, 웹 UI, 일반화한 콘텐츠 기준, 로컬 테스트만 포함합니다. 제작자의 로그인 세션·인증정보·기존 작성 글·예약 내역·수집 자료·개인 페르소나·대화 기록·Git 이력은 포함하지 않습니다. `data`는 실행 중 각 사용자 컴퓨터에서 새로 만들어집니다.

## 발행과 예약

앱의 로컬 대기열은 Threads 네이티브 예약 및 제작자의 Codex/Slack 자동화와 별개입니다. 내려받는 것만으로 8회/일 자동 검수·보충 작업이 설치되지 않습니다. 로컬 대기열을 사용할 때는 앱 실행 유지와 올바른 계정·내용·시간 확인이 필요합니다.

이 패키지 검증에서는 실제 게시·예약·유료 AI 호출을 하지 않습니다. 각자 로그인한 실제 서비스에서의 발행은 별도 확인해야 합니다. 비밀번호, 쿠키, 세션 파일은 다른 사람에게 공유하지 마세요.

## 검증

```sh
npm test
```

공개 글 URL·작성자·전체 이어지는 글의 검증과 대기열 상태/중복 방지 로직에 대한 로컬 테스트입니다. 서비스 UI 변경 시 크롤링·발행 기능은 추가 수정이 필요할 수 있습니다.
